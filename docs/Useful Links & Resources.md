## 🔗 Useful Links & Resources

A curated list of tools, guides, and communities to help you get the most out of your DIY Steam Machine.

---

## 🛠️ **System Tools**
* **[LACT](https://github.com/ilya-zlobintsev/LACT)**: The best tool for AMD GPU control (Overclocking, undervolting, and custom fan curves).
* **[MangoHud](https://github.com/flightlessmango/MangoHud)**: High-performance Vulkan/OpenGL overlay for monitoring FPS, temps, and load.
* **[GOverlay](https://github.com/benjamimgois/goverlay)**: Graphical UI to easily manage and style your MangoHud overlay.
* **[ProtonUp-Qt](https://github.com/DavidoTek/ProtonUp-Qt)**: Install and manage **Proton-GE** and **Wine-GE** with a single click.

---

## 🎮 **Game Launchers & Compatibility**
* **[ProtonDB](https://www.protondb.com/)**: Check compatibility reports and user tweaks for thousands of Steam games.
* **[Lutris](https://lutris.net/)**: The all-in-one launcher for GOG, Epic, Ubisoft, and classic emulators.
* **[Heroic Games Launcher](https://heroicgameslauncher.com/)**: Open-source alternative for Epic, GOG, and Amazon Games.
* **[Bottles](https://usebottles.com/)**: Run Windows apps and non-gaming software in isolated "bottles".
* **[Emudeck](https://github.com/dragoonDorise/EmuDeck)**: EmuDeck is a collection of scripts that allows you to autoconfigure your Steam Deck or any other Linux Distro, it creates your roms directory structure and downloads all of the needed Emulators for you along with the best configurations for each of them.
* **[Ludusavi](https://github.com/mtkennerly/ludusavi)**: Ludusavi is a tool for backing up your PC video game save data.

---

## 📚 **Deep Dive: Arch Wiki & Guides**
* **[Arch Wiki - Gaming](https://wiki.archlinux.org/title/Gaming)**: The definitive guide to gaming on Arch.
* **[Arch Wiki - AMDGPU](https://wiki.archlinux.org/title/AMDGPU)**: Official documentation for the AMD open-source driver.
* **[Arch Wiki - Intel Graphics](https://wiki.archlinux.org/title/Intel_graphics)**: Official documentation for Intel's open source driver stack.
* **[Arch Wiki - NVIDIA Graphics](https://wiki.archlinux.org/title/NVIDIA)**: This article covers the official NVIDIA graphics card drivers.
* **[Arch Wiki - Nouveau](https://wiki.archlinux.org/title/Nouveau)**: This article covers the reverse-engineered NOUVEAU driver for NVIDIA graphics cards.
* **[Arch Wiki - Improving Performance](https://wiki.archlinux.org/title/Improving_performance)**: A must-read for system-wide optimizations.
* **[Arch Wiki - Vulkan](https://wiki.archlinux.org/title/Vulkan)**: Vulkan is a low-overhead, cross-platform 3D graphics and compute API. First released in 2016, it is a successor to OpenGL.
* **[Arch Wiki - Wayland](https://wiki.archlinux.org/title/Wayland)**: Wayland is a display server protocol. It has been widely established as the successor of the X Window System.
* **[EndeavourOS Gaming 101](https://discovery.endeavouros.com/gaming/gaming-101/2022/01/)**: An excellent, user-friendly entry point for new users.
* **[Mesa 3D](https://docs.mesa3d.org/envvars.html)**: The complete list of variables to tweak performance and debug the Mesa/RADV driver stack.
* **[Command line options](https://developer.valvesoftware.com/wiki/Command_line_options)**: Command line options (also referred as command line
arguments, command line parameters or launch options on **[Steam](https://developer.valvesoftware.com/wiki/Steam)**.
